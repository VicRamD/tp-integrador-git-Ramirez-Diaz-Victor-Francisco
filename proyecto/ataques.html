Ataques Principales

ATAQUES / TÉCNICAS DE ATAQUE

  • Phishing: Engaño mediante mensajes falsos para robar información
  • DDoS: Saturación masiva de un servicio o red
  • SQL Injection: Inserción de código SQL malicioso en aplicaciones
  • Fuerza bruta: Prueba masiva de contraseñas
  • Credential stuffing: Uso automatizado de credenciales filtradas en otros servicios para acceder a nuevas cuentas.
  • Man-in-the-Middle (MitM): Ataque donde el atacante intercepta y puede modificar la comunicación entre dos partes.
  • Session hijacking: Secuestro de una sesión autenticada
  • XSS (Cross-Site Scripting): Inyección de scripts maliciosos en sitios web que se ejecutan en el navegador de otros usuarios.

TIPOS DE MALWARE

  • Virus: Se adjunta a archivos y se replica
  • Gusano (Worm): Se propaga automáticamente en redes
  • Troyano: Malware disfrazado de software legítimo
  • Ransomware: Cifra archivos y exige rescate
  • Spyware: Espía actividad del usuario
  • Keylogger: Registra pulsaciones del teclado
  • Adware: Muestra publicidad invasiva
  • Killware: Diseñado para causar daño físico
