# Ciberseguridad - Conceptos Básicos

## Descripción

Este pequeño proyecto contiene conceptos básicos del mundo de la ciberseguridad como seguridad de la información o la Triada CIA o tipos de ataques.

## Objetivo

El objetivo de este repositorio es documentar los conceptos fundamentales sobre el ámbito de la ciberseguridad para todos aquellos que deseen adentrarse en él.

## Estructura del repositorio

```text
tp-integrador-git-Ramirez-Diaz-Victor-Francisco/
│
├── README.md
├── ENTREGA.md
└── proyecto/
    ├── index.html
    └── ataques.html
```

- El directorio raiz contiene todos los archivos del proyecto.
- README.md (este archivo) contiene una descripción general de que trata el proyecto.
- ENTREGA.md contiene un registro del proceso de trabajo
- index.html contiene conceptos básicos para la ciberseguridad
- ataques.html contiene una lista de ataques más comunes y de tipos de malware
